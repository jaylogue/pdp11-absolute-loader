# LISTING OF PDP-11 ABSOLUTE LOADER

ABSLA7.LST is an ASCII recreation of the original assembly listing for the **DEC PDP-11 Absolute Loader program**.

The listing was published by the Digital Equipment Corporation as document DEC-11-UABLA-A-LA, *Listing of PDP-11 Absolute Loader*, June 1975.

This version was generated from a scanned copy of the original courtesy of the
[Vintage Technology Digital Archive](https://vtda.org) ([DEC-11-UABLA-A-LA_PDP-11AbsoluteLoaderListing_Jun75.pdf](https://vtda.org/docs/computing/DEC/PDP-11/DEC-11-UABLA-A-LA_PDP-11AbsoluteLoaderListing_Jun75.pdf)).

The conversion to ASCII text was performed using an AI-assisted OCR process, followed by
manual review and correction. Every effort was made to ensure the faithfulness of the final document,
down to the precise spacing of fields in the listing. Nonetheless, some trivial inaccuracies likely
remain due to the poor quality of the scan (most notably, confusion between commas and periods).

The file ABSLA7.MAC contains a copy of the listing converted back into a MACRO-11-compatible assembly
file. Assembling this file using a modern recreation of the MACRO-11 assembler ([Rhialto/macro11](https://gitlab.com/Rhialto/macro11))
produces a near-identical listing file; the primary differences being the symbol table and pagination header formats.

The file names come from the original listing.
